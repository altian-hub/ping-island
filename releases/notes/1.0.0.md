## 亮点
- 新增迷你模式：一种省电界面，平时完全不显示，只在需要你做决定（允许 / 拒绝 / 回答提问）时弹出一张卡片。卡片会从菜单栏图标下方弹出，也可以通过刘海面板上的按钮进入迷你模式。
- 新增“自动允许所有 Claude Code 权限”设置（默认关闭）。开启后，所有 Claude Code 会话的权限请求都会自动允许；提问仍会显示。每条自动允许的请求都会记录到 `~/Library/Logs/PingIsland/auto-approvals.jsonl`，可在设置中直接打开。
- 新增浮动 Buddy 界面：可以把 Island 从刘海分离成一个可拖动的浮动气泡，拖回顶部中央即可重新停靠。
- 会话列表重新设计为单列布局，并显示 Claude 的权限模式（Auto / Edit / Plan）以及按阶段着色的边框。
- 展开面板中显示 Claude 和 Codex 的配额用量，并支持子代理会话。

## 修复
- Claude Code 的 AskUserQuestion 现在会在终端中显示原生选项，包括 auto 模式和“为本会话允许”模式。
- 修复了因每次追加都重新解析整个对话记录、以及会话缓存从不释放而导致的卡顿和内存增长。
- 隐藏了 Claude 生成标题时产生的辅助会话和空白的 swarm 会话。
- 恢复并加固了 Codex 的完成提示和提醒音，避免重新导入的历史会话误触发。
- 远程 SSH：支持显式端口、睡眠断开后自动重连、修复重复的远程审批请求，并在桥接部署失败时给出提示。
- 新增 OpenClaw 和 OpenCode 集成，同步 macOS 专注模式 / 勿扰模式到应用内静音，并新增“清理已结束会话”按钮。

## Highlights
- New Mini mode: a battery-saver surface that shows nothing at all until a session needs a decision (Allow / Deny / answer a question). The card drops down from the menu-bar icon, and a notch button switches into Mini mode.
- New "Auto-allow all Claude Code permissions" setting (off by default). When on, every Claude Code permission request is allowed without asking; questions still show. Each auto-allowed request is logged to `~/Library/Logs/PingIsland/auto-approvals.jsonl`, which Settings can reveal in Finder.
- New floating Buddy surface: detach Island from the notch into a draggable bubble, and drop it near the top center to dock it again.
- Redesigned single-column session rows, with Claude's permission mode (Auto / Edit / Plan) and phase-colored borders.
- Claude and Codex quota usage in the expanded panel, plus subagent session support.

## Fixes
- Claude Code's AskUserQuestion now shows its native picker in the terminal again, including in auto mode and "Allow for Session" mode.
- Fixed lag and memory growth from re-parsing the whole transcript on every append and from parser caches that were never released.
- Hid Claude title-generation helper sessions and phantom swarm sessions.
- Restored and hardened Codex completion and attention sounds, so re-imported historical threads no longer fire them.
- Remote SSH: explicit ports, reconnect after sleep, no more duplicate remote approval requests, and a visible error when a bridge deploy fails.
- Added OpenClaw and OpenCode integrations, mirrored macOS Focus / Do Not Disturb into the in-app mute, and added a Clean Dead Sessions button.
